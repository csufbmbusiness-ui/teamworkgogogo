# 廚藝課食材善用與零浪費實踐調查問卷 — 語意情緒與決策分析儀表板

來源：https://maroon-callida-58.tiiny.site/

- `index.html` — 主程式（單一檔案，HTML/CSS/JS 全部內嵌，已移除 tiiny.host 的廣告與追蹤腳本）
- `original-download.html` — 從網站下載的原始版本（備份）

## 使用方式
直接用瀏覽器開啟：

    open index.html

或啟動本機伺服器：

    python3 -m http.server 8000   # 然後打開 http://localhost:8000
